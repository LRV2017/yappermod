# HOW TO INSTALL YAPPERMOD

Get YapperMod up and running in just a few simple steps!

### 🟢 STEP 1 — DOWNLOAD
Head over to the GitHub repository and click the green **Code** button. Select **Download ZIP**.

### 📦 STEP 2 — EXTRACT
Once the download finishes, locate the ZIP file and extract its contents to a folder of your choice.

### ⚙️ STEP 3 — INSTALL
Open the extracted folder and run **YapperMod Setup.exe**. Follow the setup instructions to complete the installation.

### 🎉 YOU'RE DONE!
YapperMod is now ready to use. Enjoy!
